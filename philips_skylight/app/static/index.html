Keep power in sync

Check the physical panel, then tell Home Assistant its current power state. This does not send a command.

Power is tracked from commands and remote presses. Check it again after a restart, outage, or missed remote press.

Download Home Assistant dashboard card

Built-in dashboard controls, including power and scene state correction. Add a Manual card to your dashboard and paste the downloaded configuration. Entity IDs are filled in for your installation.

Transmitter setup

Choose the advertising action and name sensor from the same ESPHome Bluetooth proxy.

Already configured lights retain their entity IDs and sequence storage.

Download proxy firmware configuration

Merge it with your existing ESPHome configuration, preserving Wi-Fi, API and OTA settings. Compile and install with ESPHome Device Builder. Enable the proxy’s permission to perform Home Assistant actions for remote tracking.

Pair this transmitter

Use pairing if the panel ignores commands. Cycle its mains power, then send the pairing request. The panel should blink. Pairing may replace the original remote’s pairing on some panels.

The request lasts about ten seconds. Check the panel and original remote afterward, then synchronize power above.
