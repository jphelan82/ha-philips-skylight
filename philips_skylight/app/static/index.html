Download ESPHome Skylight package

Extract skylight-transmitter.yaml and the components folder beside your existing ESPHome node YAML. Add this entry to its packages mapping:

packages:
  skylight: !include skylight-transmitter.yaml

Keep your node name, board, Wi-Fi, API encryption and OTA settings. If you already have a packages mapping, add just its skylight entry. Compile and install with ESPHome Device Builder. The download includes full instructions; an already compatible proxy needs no update.

Transmitter settings

Advanced transmitter selection

Use this only if your proxy has a custom adapter name or cannot be matched automatically. Select an action and sensor from the same device.

Existing entity IDs, pairing and sequence storage are preserved. Saving a transmitter does not pair it or operate the light.

Remote tracking permission

In the proxy's ESPHome integration options, enable Allow the device to perform Home Assistant actions. This lets BLE presses from other compatible remote/control panels update the recorded state.

Open ESPHome integrations

Check this permission yourself; finding a transmitter does not verify it. After recording the starting state, press a remote button and check the native light entity. A received press is not confirmation that the panel acted on it.

Pair the transmitter on first setup

The panel ignores a new HA transmitter until you pair it. If this transmitter already controls your panel, skip this step. Updates do not need pairing again. On some panels, pairing can replace the original remote's pairing.

  1. Tick the box below.
  2. Switch the panel's mains power off at the wall switch or breaker.
  3. Switch the mains power on again.
  4. Select Send pairing request straight away. The request lasts about ten seconds, and the panel blinks.

Check the physical panel and original remote afterward. Pairing completion is not an acknowledgment; record the starting state again.

Panel ignores commands after a rebuild or restore

The panel ignores any command whose sequence number is not higher than the last one it accepted from this transmitter. If Home Assistant was rebuilt without a backup, or restored from an older backup, its counter is too low. Skipping forward fixes that without pairing again.

Try this only when the paired transmitter worked before and now has no effect, while the proxy is connected and the original remote still works. Each skip uses about one million of the counter's 16.7 million numbers. Skipping sends no light command.

Record initial state

Look at the panel to record whether it is on or off. Choose its mode below, or leave it Unknown.

Press a button on your remote control panel to update in real time.

These choices only update Home Assistant's record. Power still needs an observation because the remote's power button only toggles. A received mode press also records power as on.

Repeat after a restart, outage, mains power change or missed BLE press. State is estimated from commands and received remote presses. If unreliable, use direct toggle, mode and dim commands and ignore the estimates.

Dashboard controls · optional

Use the native entities as they are, or add the Skylight card. It combines standard Home Assistant controls with a separate state-correction view. No HACS or custom resource is needed.

Create opens an existing Skylight dashboard if one is already present. Your current dashboards are never replaced.
