# Philips Skylight add-on

Local power, scenes, relative dimming, pairing and setup for the Philips Skylight
ceiling panel. Uses your ESPHome Bluetooth proxy and Home Assistant's native
light integration. **No MQTT broker, cloud account or separate Bluetooth adapter
is required.**

Open the web UI after starting the add-on. It installs the bundled companion
integration, detects an existing Skylight entity, and guides fresh installations
through transmitter selection and pairing. See the Documentation tab for setup,
firmware, state synchronization and recovery instructions.
